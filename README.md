# B-gjengen (flyttet)

Appen ligger nå i `siggiesmalls/vibe-check`, mappen `b-gjengen/`, og er live på
https://siggiesmalls.github.io/vibe-check/b-gjengen/. Gjør endringer der.

Dette repoet holdes bare i live for gamle lenker: `index.html` sender videre til
den nye siden, og den timevise jobben skriver fortsatt `cal/*.ics` her (lest fra
den nye siden), så gamle kalenderabonnement fortsetter å oppdateres.
